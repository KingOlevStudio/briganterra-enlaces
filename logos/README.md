# Logos de las plataformas

SVG descargados de [Simple Icons 16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0/icons), bajo [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/16.0.0/LICENSE.md).

Archivos originales: `https://cdn.jsdelivr.net/npm/simple-icons@16.0.0/icons/{youtube,instagram,tiktok,discord,kofi}.svg`.

Las marcas pertenecen a sus respectivos titulares. Se usan para identificar los enlaces a los perfiles de Briganterra; el CSS los muestra en blanco para asegurar el contraste.
